Djinn v0.2.3 · Programme

Cette version précise le fonctionnement de « Mon programme pour aujourd’hui » :
- tous les choix restent visibles pendant la journée ;
- « Fait » biffe la tâche et devient « Annuler » ;
- « Annuler » remet la tâche dans l’état à faire ;
- « Repousser » est mémorisé et reste visible dans le programme ;
- au premier lancement d’un nouveau jour, le programme de la veille est clôturé ;
- les tâches encore actives sont enregistrées comme « Non réalisé » ;
- « Fait » n’est plus une action de la page Tâches ;
- l’historique de chaque tâche peut être complété ou corrigé a posteriori.

La clé locale reste djinn-v0100-state afin de préserver les données existantes.
