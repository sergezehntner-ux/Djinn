Djinn v0.2.1 · Apprentissage

Nouveauté ciblée : apprentissage des acceptations contextuelles.
- « D’accord, je m’y mets » mémorise maintenant le contexte (temps, énergie, moment, lieu).
- Une acceptation ne marque plus automatiquement la tâche comme faite.
- Les acceptations répétées dans un contexte proche favorisent légèrement la tâche dans ce même contexte.
- La rubrique Apprentissages distingue acceptations, refus et tâches réellement faites.
- Les données existantes sont conservées via la clé locale djinn-v0100-state.
