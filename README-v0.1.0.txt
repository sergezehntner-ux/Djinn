DJINN v0.1.0 — PREMIER PROTOTYPE PWA
====================================

Contenu :
- identité visuelle Djinn / SZ
- écran principal « Que faisons-nous maintenant ? »
- temps disponible + niveau d'énergie
- petit moteur local de suggestion
- boutons « Je le fais », « Pas envie », « Autre chose », « Pourquoi ? »
- gestion simple des tâches
- premiers apprentissages locaux
- mise en page responsive pour écran extérieur / grand écran Fold
- manifest PWA + service worker

Installation sur GitHub :
1. Extraire le ZIP sur le smartphone.
2. Ouvrir le dépôt GitHub Djinn.
3. + puis Upload files.
4. Charger TOUS les fichiers extraits à la racine du dépôt.
5. Confirmer le commit.
6. Attendre la publication GitHub Pages puis ouvrir l'application.

Important :
Cette version n'utilise encore ni IA, ni photo réelle, ni voix, ni bridge Android.
Toutes les données de test sont locales au navigateur.
