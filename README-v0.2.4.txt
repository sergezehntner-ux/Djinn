Djinn v0.2.4 · Prévoir

Cette version ajoute une seule fonction : « Prévoir pour ».
- un champ date facultatif est disponible dans chaque tâche ;
- le jour prévu (ou à la première ouverture après cette date), la tâche est ajoutée automatiquement à « Mon programme pour aujourd’hui » ;
- le champ « Prévoir pour » se vide automatiquement dès cette activation ;
- l’arrivée au programme est enregistrée dans l’historique de la tâche ;
- la tâche suit ensuite exactement les comportements habituels : Fait, Annuler, Repousser, Non réalisé, etc.

La clé locale reste djinn-v0100-state afin de préserver les données existantes.
